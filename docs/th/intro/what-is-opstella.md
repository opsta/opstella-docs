## What is Opstella?

<img class="light-only" alt="Opstella Overview" src="/images/intro/what-is-opstella/opstella-overview.svg" data-zoomable />
<img class="dark-only" alt="Opstella Overview" src="/images/intro/what-is-opstella/opstella-overview-dark.svg" data-zoomable />

**Opstella คือ Single Portal สำหรับงาน DevSecOps Platform Engineering แบบครบวงจร** ที่ผสานการพัฒนา (Development) ความปลอดภัย (Security) และการปฏิบัติการ (Operations) เข้าด้วยกันอย่างไร้รอยต่อ เพื่อมอบประสบการณ์การนำแอปพลิเคชันขึ้นสู่ระบบที่ปลอดภัยและมีประสิทธิภาพ สำหรับองค์กรที่ให้ความสำคัญกับการส่งมอบซอฟต์แวร์ที่รวดเร็ว เชื่อถือได้ และขยายขนาดได้ โดยไม่ต้องบริหารจัดการเครื่องมือต่าง ๆ ด้วยตนเองโดยตรง **Opstella ทำงานอัตโนมัติและบริหารจัดการงานข้าม Kubernetes, DevSecOps และเครื่องมือ Observability ให้ทั้งหมด**

## <ins>**Opstella Key Features**</ins>

### Platform Management on Multi-Cloud

![Opstella Applications Hierarchy!](/images/intro/what-is-opstella/application-hierarchy.svg){data-zoomable}

Opstella บริหารจัดการ Environment ของแอปพลิเคชันทั้งหมดผ่าน Single Portal ที่ผสานรวมกับสถาปัตยกรรมแบบ Kubernetes-native

### Application and Microservices Management

![Opstella Platform Relations!](/images/intro/what-is-opstella/platform-relations.png){data-zoomable}

Opstella ช่วยให้คุณ deploy, monitor, ตรวจสอบ และแก้ไขปัญหาสถานะสุขภาพของแอปพลิเคชันแบบเรียลไทม์ได้อย่างง่ายดายจากแดชบอร์ดเดียวที่ใช้งานสะดวก

### Single Sign-On DevSecOps Tools

![Opstella Single Sign-On!](/images/intro/what-is-opstella/sso.png){data-zoomable}

Opstella รวมศูนย์การยืนยันตัวตนและการกำหนดสิทธิ์การเข้าถึงเครื่องมือ DevSecOps ทั้งหมดไว้ใน Portal เดียว

### Enterprise-Ready DevSecOps Templates

![Opstella Enterprise DevSecOps Templates!](/images/intro/what-is-opstella/sotfware-template.png){data-zoomable}

Opstella ช่วยให้คุณ deploy ได้เร็วขึ้นด้วยเทมเพลตการตั้งค่า DevSecOps ที่ปลอดภัยและพร้อมใช้งาน ออกแบบมาให้เหมาะกับความต้องการระดับองค์กร

### Centralized Security Dashboard

![Opstella Centralized Security Dashboard!](/images/intro/what-is-opstella/defectdojo.png){data-zoomable}

Opstella รวบรวมรายงานจากเครื่องมือความปลอดภัยตามแนวทาง Gartner CNAPP ทั้งหมดมาไว้ในแดชบอร์ดความปลอดภัยรวมศูนย์เดียว เพื่อช่วยให้ทีมพัฒนาและทีมความปลอดภัยระบุและแก้ไขช่องโหว่ได้อย่างรวดเร็ว

### Unified and Automated Observability Dashboard

![Opstella Observability!](/images/intro/what-is-opstella/grafana.png){data-zoomable}

Opstella เป็นแดชบอร์ดตรวจสอบแบบครบวงจรสำหรับประสิทธิภาพแอปพลิเคชัน การแก้ไขปัญหา และข้อมูลเชิงลึกข้ามบริการต่าง ๆ โดยใช้ Metrics, Logs และ Traces เพื่อระบุสาเหตุของปัญหาได้อย่างรวดเร็ว
